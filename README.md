# LoRa APRS Tracker 9M2PJU Mod - Release

Public release repository for the **9M2PJU Mod LoRa APRS Tracker** (Heltec Wireless Tracker).

This repo contains:
- **Web installer** (`docs/`) - hosted at [lora.hamradio.my](https://lora.hamradio.my) via Cloudflare Pages
- **Firmware binaries** (`docs/firmware/`) - Heltec Wireless Tracker build artifacts

This public repo is updated
automatically by CI whenever new firmware is built, so users always have access to
the latest web installer and binaries.

## Install firmware

Visit the web installer at **https://lora.hamradio.my** and follow the on-screen
instructions. Use a Chromium-based browser (Chrome, Edge) over USB.

Heltec Wireless Tracker download mode: press **BOOT + RST** together, screen goes
blank.
